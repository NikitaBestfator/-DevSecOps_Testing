1. Чек-лист
    1. Проверка на дубликаты (Спорная):
    Если задача с таким name уже есть... 409 Conflict.
    Данные: Пустая база.
    Ожидание: Второй POST с тем же именем вернет 409.
    Запрос проверки: GET /todoitems (убедиться, что задача одна).
    2. Проверка PUT (Спорная):
    Для смены только статуса достаточно передать isComplete... name сохранит прежнее значение.
    Данные: Существующая задача (например, id=1, name="Тест", isComplete=false).
    Ожидание: PUT вернет 204, name останется "Тест".
    Запрос проверки: GET /todoitems/1.
    3. Проверка DELETE (Спорная):
    Повторный DELETE с тем же id также возвращает 204.
    Данные: Существующая задача (id=2).
    Ожидание: Первый и второй DELETE вернут 204.
    Запрос проверки: GET /todoitems/2 (убедиться, что вернет 404).
    4. Проверка PATCH (Контрольная, может быть верной):
    Изменяет только поля, переданные в JSON.
    Данные: Существующая задача (id=3, name="Тест 2").
    Ожидание: PATCH вернет 204, name не изменится.
    Запрос проверки: GET /todoitems/3.

Проверка сервиса Scalar:
1. POST /todoitems (Body: {"name":"Задача А","isComplete":false})
Результат: 201 Created. Запишите id = 1 (или тот, что выдаст сервер).
2. POST /todoitems (Body: {"name":"Задача А","isComplete":true}) — проверяем дубликат.
Результат: 201 Created. Запишите id = 2. (Черновик ошибся, дубликат создался!)

Часть Б: Подготовка к PUT и PATCH
3. POST /todoitems (Body: {"name":"Задача Б","isComplete":false})
Результат: 201 Created. Запишите id = 3.

Часть В: Сравнение PATCH и PUT (на одной и той же задаче id=3)
4. PATCH /todoitems/3 (Body: {"isComplete":true})
Результат: 204 No Content.
5. GET /todoitems/3
Результат: 200 OK. Body: {"id":3,"name":"Задача Б","isComplete":true}. (Черновик верен: имя сохранилось).
6. PUT /todoitems/3 (Body: {"isComplete":false}) — проверяем PUT.
Результат: 204 No Content.
7. GET /todoitems/3
Результат: 200 OK. Body: {"id":3,"name":null,"isComplete":false}. (Черновик ошибся: имя стёрлось в null!)

Часть Г: Проверка удаления (на задаче id=2)
8. DELETE /todoitems/2
Результат: 204 No Content.
9. DELETE /todoitems/2 (повторно)
Результат: 404 Not Found. (Черновик ошибся: сервер вернул 404, а не 204).
10. GET /todoitems/2
Результат: 404 Not Found.
