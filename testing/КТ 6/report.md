1. Чек-лист
    1. Проверка на дубликаты (Спорная):
    Фраза: «Если задача с таким name уже есть... 409 Conflict».
    Данные: Пустая база.
    Ожидание: Второй POST с тем же именем вернет 409.
    Запрос проверки: GET /todoitems (убедиться, что задача одна).
    2. Проверка PUT (Спорная):
    Фраза: «Для смены только статуса достаточно передать isComplete... name сохранит прежнее значение».
    Данные: Существующая задача (например, id=1, name="Тест", isComplete=false).
    Ожидание: PUT вернет 204, name останется "Тест".
    Запрос проверки: GET /todoitems/1.
    3. Проверка DELETE (Спорная):
    Фраза: «Повторный DELETE с тем же id также возвращает 204».
    Данные: Существующая задача (id=2).
    Ожидание: Первый и второй DELETE вернут 204.
    Запрос проверки: GET /todoitems/2 (убедиться, что вернет 404).
    4. Проверка PATCH (Контрольная, может быть верной):
    Изменяет только поля, переданные в JSON.
    Данные: Существующая задача (id=3, name="Тест 2").
    Ожидание: PATCH вернет 204, name не изменится.
    Запрос проверки: GET /todoitems/3.
