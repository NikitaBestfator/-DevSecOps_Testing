## Объяснение: Контейнеры общаются по внутренней сети Docker.
## База данных использует volume (pgdata), поэтому при перезапуске контейнера api (как в K4-04) данные заявок сохраняются.

# 4. Объяснение мониторинга и восстановления
## Объяснение: Prometheus собирает метрики с api и web. Если api падает, web возвращает 503,
## а Prometheus фиксирует up=0. Восстановление — это перезапуск контейнера (start api), а не откат версии кода.
