# K2-02. Свой Dockerfile

## Содержимое lab/Dockerfile
FROM python:3.12-slim
LABEL course.student="18052007"
WORKDIR /app
ENV PYTHONUNBUFFERED=1
COPY app.py .
COPY index.html .
RUN mkdir -p /data && chown -R 10001:10001 /data
USER 10001:10001
EXPOSE 8000
CMD ["python", "app.py"]

## Сборка
docker build -f lab/Dockerfile -t devops-student:v1 lab

## Проверка понимания
Почему EXPOSE не заменяет -p?
EXPOSE — это метаданные образа, документирующие, какой порт слушает приложение внутри контейнера. Он не открывает доступ к этому порту с хоста. Для публикации порта на хост используется флаг -p при запуске контейнера (или секция ports в compose), который создает проброс (NAT) с порта хоста на порт контейнера.
