Какой порт нужен между контейнерами: 8080 или 8000?
8000. Порт 8080 — это внешний порт, на который мы пробрасываем трафик с хоста (127.0.0.1:8080). Внутри Docker-сети контейнеры общаются по внутреннему порту 8000, на котором слушает сервис api. При попытке использовать 9999 (или 8080) web не смог достучаться до api и вернул ошибку 503.
