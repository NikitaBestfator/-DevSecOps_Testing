Причина: web работает, но при попытке проксировать запрос к /api/requests он стучится к api, который остановлен.
 Поэтому health (локальный) работает, а запросы к api падают с 503.

Восстановление:
docker compose start api
Создал новую заявку на localhost:8080 - успешно.

Почему health у web остался успешным?
Эндпоинт /health у web проверяет только сам процесс web (отвечает {"process": "running", "role": "web"}).
 Он не проверяет доступность api. Поэтому health возвращает 200, даже если api лежит.
